# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the
work. Harassment and personal attacks are not tolerated.

To report a problem, contact the maintainer
([@wpkc0429](https://github.com/wpkc0429)) through a
[private security advisory](https://github.com/wpkc0429/agent-squiggles/security/advisories/new)
or a direct message on GitHub. Reports are handled confidentially.
